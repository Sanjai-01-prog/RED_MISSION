# RED MISSION — Blood Donation Management & Emergency Donor Network

RED MISSION is a mission-critical, secure healthcare web application dedicated to voluntary blood donation management, rapid donor geo-matching, emergency hospital requisition coordination, mobile camp slot reservation, and digital certificate verification.

---

## Phase 1 Architecture Overview

Phase 1 establishes the production-grade foundation: Public Homepage, User Authentication, Multi-Step Registration with Dual Verification (Mobile + Email), Admin Authentication with Dual 2FA (Mobile OTP + Email OTP), Three-tier Role-Based Access Control (`SUPER_ADMIN`, `ADMIN`, `MODERATOR`), Server-Side Security Infrastructure, and Relational Database Schema.

## Technology Stack

- **Frontend**: React 18, Vite 5, Tailwind CSS 3, Lucide React
- **Backend**: Node.js (v24), Built-in HTTP REST Router, `node:crypto` (Scrypt, HMAC-SHA256, CSPRNG)
- **Database**: Native Relational SQLite (`node:sqlite`) with Foreign Keys, WAL mode, Indexes, and ACID transactions
- **Authentication**: Stateful sessions + signed bearer tokens / HTTP-only cookies, sliding window rate limiter, 5-attempt lockout, dual OTP multi-factor verification

---

## 17 Relational Database Tables

1. `users`: Citizen and donor profiles with scrypt password hashes and lockout trackers.
2. `user_verifications`: Mobile and Email verification timestamps.
3. `otp_records`: Non-reusable, expiring, single-use OTP hashes with attempt limits.
4. `password_reset_tokens`: Cryptographically secure single-use password recovery tokens.
5. `user_sessions`: User sessions with 30-min inactivity limits and 24-hr max duration.
6. `login_attempts`: Security auditing of all successful and failed logins.
7. `user_security_activities`: Security event timeline displayed under My Account → Security.
8. `admin_roles`: Reference table for `SUPER_ADMIN`, `ADMIN`, and `MODERATOR`.
9. `role_permissions`: Granular operational permissions mapped to roles.
10. `admin_accounts`: Administrator credentials, role assignments, and lockout trackers.
11. `admin_invitations`: Expiring, single-use invitation tokens generated by Super Admin.
12. `admin_otp_records`: Dual 2FA multi-factor records verifying BOTH mobile and email OTPs.
13. `admin_sessions`: Admin sessions with 30-min inactivity limits and 8-hr max duration.
14. `security_audit_logs`: Tamper-evident audit log of all administrative actions.
15. `account_deletion_records`: Audit compliance logs for permanent account removals.
16. `anonymized_donation_records`: Statistical historical donation records purged of personal PII.
17. `retained_donation_proof_metadata`: Document hashes and verification metadata.

## Quick Start & Running Commands

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Backend Server (Port 5000)
```bash
npm run server
```
*Initializes database schema at `server/data/red_mission.db` and provisions the initial Super Admin account (`superadmin`).*

### 3. Start Frontend Dev Server (Port 3000)
```bash
npm run dev
```

### 4. Production Build
```bash
npm run build
```
